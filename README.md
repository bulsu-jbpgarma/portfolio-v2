# Ben. — Personal Portfolio

A personal portfolio built with HTML, CSS, and JavaScript to showcase my projects, interests, and journey as a third-year BSIT student aspiring to become a front-end developer.

**[Live Website](https://portfolio-v2-benny-6400.vercel.app/)** · **[GitHub Profile](https://github.com/bulsu-jbpgarma)** · **[LinkedIn](https://www.linkedin.com/in/john-benedict-p-garma-255273443/)**

## About

Ben. is my personal portfolio website, created to present my work in web development and UI/UX design through a clean, minimalist interface.

The website highlights selected projects, introduces my interests as a developer, and provides ways to connect with me.

## Features

- Personal introduction and profile
- Selected projects with technology highlights
- Section-based navigation
- Light and dark theme toggle
- Contact information and social links
- Minimalist interface with responsive styling

## Tech Stack

- **HTML5** — Page structure and content
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Interactive elements and theme switching

## Featured Projects

| Project | Description | Technologies |

| MediSync | Hospital HR management system for staff scheduling and credential tracking | React, Firebase, Tailwind CSS |

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/bulsu-jbpgarma/portfolio-v2.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio-v2
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No package installation is required for the current static version.
